AO Tennis Score Tracker

Get the Android app

The app shows the same live scores, draw, schedule and standings as this website, and scorers can sign in and score from it. It works on Android 7.0 and later.

Download the latest APK

Install

  1. Download the .apk file on your phone, or copy it to the phone (USB cable, Google Drive, email or WhatsApp).
  2. Open the file from your notifications, Downloads or the Files app.
  3. If Android says installing unknown apps isn't allowed, tap Settings, turn on Allow from this source for the app you opened it with (for example Files, Chrome or Drive), then go back.
  4. Tap Install. If Google Play Protect warns that it doesn't recognise the developer, tap More details, then Install anyway.
  5. Open AO Tennis Score Tracker from your home screen or app drawer.

Updating

Download the new APK and install it the same way; it replaces the old version and you stay signed in. You never need to uninstall first. All tournament data lives on the server, so nothing on the phone is lost either way.

First open after a quiet spell

The server sleeps when nobody has used it for a while. If you see "Waking up the server", give it up to a minute.
